# 夜航音乐工作室

安装：`npm install`

本地启动：`npm run dev`，访问终端显示的地址。

类型检查：`npm run typecheck`
单元/集成测试：`npm test`
生产构建：`npm run build`

Docker 启动：`docker compose up --build -d`，访问 http://localhost:18027 。

## 轨道编组（Track Groups）

混音台支持把鼓组、和声等多层轨道组织成可嵌套的编组树：

- **层级混音**：声音链路为「子轨增益 → 各级父编组增益 → 主输出」，每一级都有独立音量与静音。
- **编组静音安全**：只把编组自身增益切到 0，子轨推子数值与静音状态原样保留；解除静音后原平衡立即恢复。
- **折叠编排**：可折叠编组只影响界面展示，录音与播放始终覆盖组内全部轨道；折叠状态下若当前选中的轨道藏在组内，编组条会明确提示所属关系。
- **拖拽改接**：拖动轨道或编组到目标编组即可改接；播放中改接采用新旧路径交叉淡变，已排队和现场按住的声音都跟随新路径，无爆音断点。拖到树的空白区域可移出编组直连主输出。
- **防环约束**：禁止把编组拖进它自己或它的后代。
- **删除二选一**：删除编组时可选择「解散」（子轨/子编组提升一层、设置全部保留）或「连同组内轨道删除」。
- **录音保护**：录音进行中锁定一切归属与层级变更，保证一次录音的提交目标不会在中途变化。
- **存档兼容**：保存格式升级为 v2，完整记录编组层级与各级混音；读取旧版 v1 存档自动迁移。恢复时若发现父编组缺失或成环，受影响节点安全提升到根层级并给出提示，校验失败则保留当前作品、不做半套覆盖。
